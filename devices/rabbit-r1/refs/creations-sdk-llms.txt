### Access Accelerometer Data with AccelerometerHandler

Source: https://context7.com/rabbit-hmi-oss/creations-sdk/llms.txt

Utilize AccelerometerHandler to get real-time motion sensor data. It provides normalized tilt values (-1 to 1) and raw acceleration. Sampling frequency is configurable.

```javascript
// Accelerometer API is injected as window.creationSensors

// Check if accelerometer is available on device
const isAvailable = await window.creationSensors.accelerometer.isAvailable();
if (!isAvailable) {
  console.log('Accelerometer not available on this device');
  return;
}

// Start receiving accelerometer data at 60Hz (default)
window.creationSensors.accelerometer.start((data) => {
  console.log('Accelerometer data:', data);
  // Normalized tilt values (-1 to 1):
  // tiltX: positive = tilt right, negative = tilt left
  // tiltY: positive = tilt forward, negative = tilt back
  // tiltZ: positive = facing up, negative = facing down

  document.getElementById('tiltX').textContent = data.tiltX.toFixed(2);
  document.getElementById('tiltY').textContent = data.tiltY.toFixed(2);
  document.getElementById('tiltZ').textContent = data.tiltZ.toFixed(2);

  // Raw acceleration values (m/s²)
  document.getElementById('rawX').textContent = data.rawX.toFixed(2);
  document.getElementById('rawY').textContent = data.rawY.toFixed(2);
  document.getElementById('rawZ').textContent = data.rawZ.toFixed(2);
}, { frequency: 60 });  // Optional: 10, 30, 60, or 100 Hz

// Stop receiving accelerometer data
window.creationSensors.accelerometer.stop();
```

### CreationStorageHandler API

Source: https://github.com/rabbit-hmi-oss/creations-sdk/blob/main/plugin-demo/reference/creation-triggers.md

Provides persistent storage for plugins with both plain (unencrypted) and secure (hardware-encrypted) options. Data must be Base64 encoded.

```APIDOC
## CreationStorageHandler API

### Description
Persistent storage API for plugins with both plain and secure storage options. All data must be Base64 encoded before storage. Storage is isolated per plugin ID. Secure storage requires Android M or higher.

### Methods
- `window.creationStorage.plain.setItem(key, value)`: Stores a key-value pair in plain storage.
- `window.creationStorage.plain.getItem(key)`: Retrieves the value for a given key from plain storage.
- `window.creationStorage.plain.removeItem(key)`: Removes a key-value pair from plain storage.
- `window.creationStorage.plain.clear()`: Clears all data from plain storage.
- `window.creationStorage.secure.setItem(key, value)`: Stores a key-value pair in secure storage.
- `window.creationStorage.secure.getItem(key)`: Retrieves the value for a given key from secure storage.
- `window.creationStorage.secure.removeItem(key)`: Removes a key-value pair from secure storage.
- `window.creationStorage.secure.clear()`: Clears all data from secure storage.

### Parameters
#### Path Parameters
- **key** (string) - Required - The key for the storage item.
- **value** (string) - Required - The Base64 encoded value to store.

### Request Example (Plain Storage)
```javascript
// Store user preferences
await window.creationStorage.plain.setItem('user_prefs', btoa(JSON.stringify({theme: 'dark'})));

// Retrieve user preferences
const prefs = JSON.parse(atob(await window.creationStorage.plain.getItem('user_prefs')));

// Remove user preferences
await window.creationStorage.plain.removeItem('user_prefs');

// Clear all plain storage
await window.creationStorage.plain.clear();
```

### Request Example (Secure Storage)
```javascript
// Store API key
await window.creationStorage.secure.setItem('api_key', btoa('secret_key_123'));

// Retrieve API key
const apiKey = atob(await window.creationStorage.secure.getItem('api_key'));

// Remove API key
await window.creationStorage.secure.removeItem('api_key');

// Clear all secure storage
await window.creationStorage.secure.clear();
```

### Response
- Returns the retrieved value (string) or `null` if the item doesn't exist.
- `clear()` methods do not return a value.
```

```APIDOC
## window.onPluginMessage - Receive Server Responses

### Description
Implement this callback function to receive messages and LLM responses from the server. Responses may contain structured JSON data in the `data` field or plain text in the `message` field.

### Method
Callback function

### Endpoint
`window.onPluginMessage`

### Parameters
#### Request Body
- **data** (object) - Contains the response from the server.
  - **message** (string) - A description of the message.
  - **pluginId** (string) - The ID of the target plugin.
  - **data** (string) - Optional. A JSON string containing response data.

### Request Example
```javascript
window.onPluginMessage = function(data) {
  console.log("Received message from server:", data);
  // data contains:
  // - message: string description
  // - pluginId: the target plugin ID
  // - data: (optional) JSON string containing response data

  // Parse structured JSON response
  if (data.data) {
    try {
      const parsed = JSON.parse(data.data);

      // Handle cat facts array
      if (parsed.facts && Array.isArray(parsed.facts)) {
        parsed.facts.forEach((fact, index) => {
          console.log(`Fact ${index + 1}: ${fact}`);
        });
      }

      // Handle paint color response
      if (parsed.paint) {
        document.getElementById('app').style.borderColor = parsed.paint;
        console.log(`Border painted: ${parsed.paint}`);
      }

      // Handle custom actions
      if (parsed.action === "updateContent") {
        document.getElementById("content").innerHTML = parsed.content;
      }
    } catch (e) {
      // data.data is not valid JSON, use as plain string
      console.log("Plain string data:", data.data);
    }
  }

  // Handle plain text message
  if (data.message) {
    console.log("Message:", data.message);
  }
};

## AccelerometerHandler API

### Description
Access real-time accelerometer data from the device. Provides raw values and a simplified tilt measurement.

### Methods
- `window.creationSensors.accelerometer.isAvailable()`: Checks if the accelerometer is available.
- `window.creationSensors.accelerometer.start(callback, options)`: Starts receiving accelerometer data.
- `window.creationSensors.accelerometer.stop()`: Stops receiving accelerometer data.

### Parameters
#### `start` method parameters
- **callback** (function) - Required - A function to be called with the accelerometer data.
  - **data** (object) - The accelerometer data object containing `x`, `y`, and `z` properties.
    - **x** (number) - Normalized value (-1 to 1) representing left/right tilt.
    - **y** (number) - Normalized value (-1 to 1) representing forward/backward tilt.
    - **z** (number) - Normalized value (-1 to 1) representing up/down orientation.
- **options** (object) - Optional - Configuration options for the accelerometer.
  - **frequency** (number) - Optional - The desired sampling frequency in Hz. Defaults to system default.

### Request Example (Check Availability)
```javascript
const isAvailable = await window.creationSensors.accelerometer.isAvailable();
```

### Request Example (Start Receiving Data)
```javascript
window.creationSensors.accelerometer.start((data) => {
  console.log('Accelerometer data:', data);
  // data = { x: 0.1, y: -0.2, z: 0.98 }
}, { frequency: 60 }); // Optional: specify sampling frequency in Hz
```

### Request Example (Stop Receiving Data)
```javascript
window.creationSensors.accelerometer.stop();
```

### Manage Persistent Storage with CreationStorageHandler

Source: https://context7.com/rabbit-hmi-oss/creations-sdk/llms.txt

Use CreationStorageHandler for storing data locally. Plain storage is unencrypted, while secure storage is hardware-encrypted (Android M+). All data must be Base64 encoded before storage. Storage is isolated per plugin ID.

```javascript
// Storage API is injected as window.creationStorage

// Plain storage (unencrypted) - for general preferences
await window.creationStorage.plain.setItem(
  'user_prefs',
  btoa(JSON.stringify({theme: 'dark', volume: 80}))
);

// Retrieve from plain storage
const storedPrefs = await window.creationStorage.plain.getItem('user_prefs');
if (storedPrefs) {
  const prefs = JSON.parse(atob(storedPrefs));
  console.log('Theme:', prefs.theme);  // Output: dark
}

// Remove specific item from plain storage
await window.creationStorage.plain.removeItem('user_prefs');

// Clear all plain storage for this plugin
await window.creationStorage.plain.clear();

// Secure storage (hardware-encrypted, Android M+) - for sensitive data
await window.creationStorage.secure.setItem(
  'api_key',
  btoa('secret_key_123')
);

// Retrieve from secure storage
const apiKey = atob(await window.creationStorage.secure.getItem('api_key'));
console.log('API Key:', apiKey);  // Output: secret_key_123

// Remove from secure storage
await window.creationStorage.secure.removeItem('api_key');

// Clear all secure storage for this plugin
await window.creationStorage.secure.clear();

// Note: Returns null if item doesn't exist
const missing = await window.creationStorage.plain.getItem('nonexistent');
console.log(missing);  // Output: null
```
